# Narlia / Cats site update rules

- Any cat-related upload or information from Darren triggers a site update and publish without needing a second instruction.
- This includes GPX files, photos, captions, corrections, milestones, birthdays/events, identity confirmations and Journey notes.
- Photos are the permanent Journey media format. Do not add videos.
- Journey photos must be kept at sensible web quality and must not be reduced to tiny thumbnail-quality files.
- New kitten photos get a first-pass identity guess where possible, but uncertain identity stays provisional until Darren confirms it.
- Once Darren confirms identity or context, publish the corrected Journey entry automatically.
- Keep the existing dashboard design and GPS behaviour intact unless Darren explicitly asks for a redesign.
- For GPX uploads, continue the established GPS cleaning, deduplication, lifetime merge and latest rolling 7-day infographic rules.
- After each update, verify the GitHub commit and Pages deployment before saying the live site is ready.
