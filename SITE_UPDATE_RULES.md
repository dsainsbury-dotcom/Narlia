# Cat Dashboard update rules

Any new cat-related input triggers a site update and publish. This includes GPX files, photos, videos, written notes, milestones, birthdays/events, identity confirmations, corrections and other story information.

- GPX: merge/deduplicate, apply the agreed GPS-noise filtering, rebuild Narlia's current GPS analytics/infographic/tabs, and publish.
- Photo/video: process for web use, add to Journey by real date/age, preserve uncertain identity until confirmed, and publish.
- Notes/text: add/update the relevant Journey story or metadata and publish.
- Identification: Narlia is tabby; Amara is lilac; Dante develops warmer brown/chocolate colouring. Make a first-pass guess on new kitten media, but do not permanently assign an uncertain image without confirmation.
- Journey can include the cats and their cat daddies Darren and Jason.
- Media failure must never take down the GPS dashboard.
- Never say updated/published/done until the GitHub write is successful and the resulting repository/public site has been checked.
