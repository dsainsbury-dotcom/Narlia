# Narlia's World

Interactive Tractive GPS dashboard for Narlia.

## GitHub Pages setup

1. Create a new PUBLIC GitHub repository.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Open repository **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages link after deployment.

The dashboard uses online satellite map tiles, so visitors need an internet connection.
